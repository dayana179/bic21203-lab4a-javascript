## Project Overview
This repository contains the solutions for Lab 4a, demonstrating core client-side JavaScript concepts including DOM selection, event listeners (`addEventListener`), input validation, conditional logic (`if...else if...else`), `for` loops, and safe DOM manipulation (`textContent` and `createElement`).

## Project Structure
* `q1/` — **Interactive Text Changer:** Updates a paragraph message when the user clicks a button.
* `q2/` — **Smart Number Validator:** Validates text input (handling empty spaces, decimals, and non-numeric strings) and compares valid numbers against 10.
* `q3/` — **Dynamic Number Generator:** Dynamically generates an ordered list (`1` to `5`) using a `for` loop without duplicating items on repeated clicks.

## How to Run Each Question
1. Clone or download this repository to your local computer.
2. Open the desired folder (`q1`, `q2`, or `q3`).
3. Double-click `index.html` to launch it in any modern desktop web browser. No external libraries or servers are required.
